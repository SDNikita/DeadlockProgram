# 🎮 Deadlock: Скрипты и Челленджи для Видео

Привет! 👋 Здесь будут находиться программы для **Deadlock**, сделанные специально для моих видео на [YouTube /https://www.youtube.com/@KeyNi3]. 

Цель этого репозитория — объединить программирование и киберспорт, создавая безумные челленджи и необычные способы управления в игре.

## 📂 Текущие проекты (Программы)

На данный момент в репозитории реализованы следующие механики:

### 1. 👁️ Скрипт "Слепота" (Blink / Eye-Tracking Challenge)
Программа, которая следит за вашими глазами через веб-камеру. 
* **Как работает:** Если вы закрываете правый глаз — правая половина экрана мгновенно заливается черным цветом. Закрываете левый — чернеет левая половина.
* **Технологии:** `OpenCV`, `MediaPipe Face Mesh`, `Tkinter`, Windows API (для сквозного клика).
* **Фишка:** Черные экраны являются "призраками" (Click-through) — вы можете продолжать стрелять и бегать сквозь них, мышь не перехватывается.
* **Файл:** `DarkGame.py` 

### 2. ✋ "Железный человек" (Управление рукой)
Играем в шутер без клавиатуры, используя только веб-камеру.
* **Как работает:** Нейросеть отслеживает положение вашей ладони и пальцев. Движение руки в воздухе управляет движением персонажа в игре, а определенные жесты активируют способности.
* **Технологии:** `OpenCV`, `MediaPipe Hands`, эмуляция клавиатуры.
* **Файл:** `DeadlockTreker.py`
