# 🎮 Deadlock: Скрипты и Челленджи для Видео

Привет! 👋 Здесь будут находиться программы для **Deadlock**, сделанные специально для моих видео на [YouTube /https://www.youtube.com/@KeyNi3]. 

Цель этого репозитория — объединить программирование и киберспорт, создавая безумные челленджи и необычные способы управления в игре.

## **❗Если будете использовать файлы в видео, прошу оставить ссылку на меня**
## 📂 Текущие проекты (Программы)

На данный момент в репозитории реализованы следующие механики:

### 1. 👁️ Скрипт "Слепота" (Blink / Eye-Tracking Challenge)
Программа, которая следит за вашими глазами через веб-камеру. 
* **Как работает:** Если вы закрываете правый глаз — правая половина экрана мгновенно заливается черным цветом. Закрываете левый — чернеет левая половина.
* **Технологии:** `OpenCV`, `MediaPipe Face Mesh`, `Tkinter`, Windows API (для сквозного клика).
* **Фишка:** Черные экраны являются "призраками" (Click-through) — вы можете продолжать стрелять и бегать сквозь них, мышь не перехватывается.
* **Файл:** `DarkGame.py` 

### 2. ✋ "Железный человек" (Управление рукой)
Играем в шутер без клавиатуры, используя только веб-камеру.
* **Как работает:** Нейросеть отслеживает положение вашей ладони и пальцев. Движение руки в воздухе управляет движением персонажа в игре, а определенные жесты активируют способности.
* **Технологии:** `OpenCV`, `MediaPipe Hands`, эмуляция клавиатуры.
* **Файл:** `DeadlockTreker.py` 

---
### 3.🎯 Deadlock Roulette (Рулетка Наказаний)
Deadlock Roulette — это прозрачный оверлей-челлендж для игры Deadlock (Valve),
созданный на Python и PyQt5. Программа работает поверх игры в невидимом
("призрачном") режиме и каждые N секунд запускает анимацию колеса рулетки,
автоматически активируя случайные наказания прямо во время матча!

🚀 Основные возможности

  - 👻 Призрачный Оверлей (Ghost Window): Использует Windows API
    (WS_EX_TRANSPARENT), благодаря чему клики мыши и нажатия клавиш пролетают
    сквозь программу прямо в игру. Игра не сворачивается и не лагает.
  - 🎰 Встроенная 3D-рулетка: Динамическая генерация и анимация вращения колеса
    рулетки прямо на экране.
  - 🎮 Автоматический ввод (Input Emulation): Программа сама зажимает клавиши
    движения, хаотично двигает прицел, заставляет перезаряжаться или случайным
    образом активирует способности.
  - ⚙️ Гибкая настройка (config.json): Возможность менять таймер, шанс выпадения
    каждого наказания (веса), а также списки горячих клавиш.
  - 📌 Трей-меню: Управление функцией паузы и выходом из программы через иконку в
    системном трее Windows.

## 🛠 Установка и запуск

Если вы хотите повторить челленджи из видео, следуйте этой инструкции:

### 1. Требования
Убедитесь, что у вас установлен **Python 3.8+**. 
Проекты тестировались на Windows (флаги прозрачности окон оптимизированы под ОС Windows).

### 2. Установка библиотек
Склонируйте репозиторий и установите необходимые зависимости:

```bash
git clone https://github.com/SDNikita/DeadlockProgram.git
pip install opencv-python mediapipe tk
```
